Try the public MCP without an account

https://jupie202020.pythonanywhere.com/mcp

Nine public tools cover searchable adverts, unsigned agreement drafts, comparison and review. Use a client that supports remote Streamable HTTP and discover the current schemas before calling. A useful first task is: “Draft terms for a one-page research brief costing USD 25. Do not sign or pay.”

Connecting grants no signing or spending authority. Public search can include clearly labelled demonstration adverts; these are not available suppliers. Private accounts and the wider installed engine have their own access, configuration and terms.
